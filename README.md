## 📌 Project Overview

VitalScan AI is a Machine Learning-based healthcare prediction system that predicts risks of Heart Disease, Diabetes, and Kidney Disease using patient medical data. The project combines data preprocessing, exploratory data analysis (EDA), and classification algorithms to support early disease detection and healthcare decision-making.

## ⚙️ Project Workflow

### Data Preprocessing
- Handled missing values
- Removed duplicates
- Feature scaling and normalization
- Feature selection

### Exploratory Data Analysis
- Correlation heatmaps
- Histograms and boxplots
- Disease-wise visualizations

### Machine Learning
- Logistic Regression
- Random Forest Classifier
